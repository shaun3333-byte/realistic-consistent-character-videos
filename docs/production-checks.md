# Production checks for consistent-character videos

Use these checks alongside the [playbook](../PLAYBOOK.md). Run them during production, after each result is available.

## Track each clip

Assign a short job label and clip IDs such as C01 and C02. Keep the following record in the working conversation or private project notes. Use character aliases and omit reference photos and private download URLs.

| Clip | Expected speaker and line | Wardrobe, location and key prop | VideoExpress render ID | Status | Replacement reason |
| --- | --- | --- | --- | --- | --- |
| C01 | | | | Planned | |

Use Planned, Submitted, Accepted, Failed or Replaced. Record the render ID when VideoExpress displays it. Keep the IDs of both the original and replacement renders so the editor uses the accepted version.

## Check before adding a clip to the timeline

1. Compare the start image with the approved anchor. Check face, hair, outfit, accessories, location and props against the character description and preceding accepted clip.
2. Preview the entire rendered clip. If the browser lets you hear playback, check the words, accent and which mouth moves. Record any audio check you could not perform.
3. Check that the first and last usable frames leave enough room for the edit. Keep the whole spoken line and any intentional reaction.
4. If the wrong person speaks, regenerate the affected clip as a solo speaking shot and put the listener's reaction in a separate silent shot if the story needs it. If the outfit or prop changes, fix the start image before retrying the video. After one replacement for the same defect, report the persistent issue before attempting another. Count confirmed failed renders separately from unclear submissions.

## Resume after an interruption

Open the saved project and inspect **My AI Videos**. Match visible renders using the recorded IDs and clip tags. For a timed-out submission, check the library before retrying. If you still cannot tell whether the app accepted it, mark that clip unresolved and continue independent clips. Resume from the first unresolved stage and reuse accepted clips.

## Review the assembled video

Play across every join to check shot order, gaps, continuity, cut-off words and overlapping audio. Confirm the saved project, intended aspect ratio and listed MP4 export. Report separately any playback checks that the available browser could not perform.
